# DevSecOps Experience

- Designed and implemented an **end-to-end DevSecOps CI/CD pipeline** for Java-based microservices using **Jenkins**, integrating security controls across the **Software Development Life Cycle (SDLC)**.

- Integrated **GitGuardian** and **Talisman** into the development workflow to detect and prevent hardcoded secrets and sensitive credentials before code reached remote repositories.

- Automated **Software Composition Analysis (SCA)** using **OWASP Dependency-Check** to identify vulnerable third-party libraries and enforce build quality gates.

- Implemented **Trivy** security scanning for source code, container images, and Kubernetes configurations, preventing deployment of **High** and **Critical** severity vulnerabilities.

- Developed and enforced **Policy-as-Code** using **Open Policy Agent (OPA)** and **Rego**, validating Dockerfiles, Kubernetes manifests, and deployment configurations against organizational security standards.

- Designed secure Docker images following **container hardening best practices**, including multi-stage builds, non-root execution, minimal base images, read-only file systems, and optimized image layers.

- Integrated **container image vulnerability scanning** into Jenkins pipelines with automated security gate enforcement before artifact promotion.

- Implemented **mutation testing** to improve unit test effectiveness and validate application resilience beyond traditional code coverage metrics.

- Established centralized **monitoring and observability** using **Prometheus** and **Grafana**, enabling proactive monitoring of application performance, infrastructure health, and security-related metrics.

- Automated security scanning and reporting within **CI/CD pipelines**, generating vulnerability reports and preventing releases that violated defined security policies.

- Built reusable **Jenkins Shared Libraries** to standardize secure build, test, scan, and deployment workflows across multiple Java microservices.

- Collaborated with development teams to remediate security findings, improve secure coding practices, and reduce application security risks throughout the development lifecycle.
